# Улучшение v8: ограниченная адаптивная поправка 0.7

## Итог

**Кандидат v8_residual070 прошёл зарегистрированные development-критерии.**
На целевом 30618 original fault-event RMSE уменьшился на **23.9844%**, на общем
наборе на **11.0012%**. На 30639 исходная fault-метрика точно совпала с v8.
Main не изменён. Это выбранный исследовательский профиль, не независимая
валидация, не официальный XYZ score и не готовая к эксплуатации новая версия.

База: `b2783206000091ab11a1c11ac3ff79082188a4fb`; численные файлы совпадают с
`e3b0c9c039d2953fbfcda51231263d38ef9f1024`.
**Опубликованный source/freeze:** `0ac3e7caa0ced4bcafc18cecb5eb226e0f7bb2da`.
Четыре плана опубликованы до соответствующих раундов: b71fe2b4, dbf8878d,
26bf53eb, d3d1e61e. Реализация опубликована после локального исполнения;
started.json до каждого replay сохраняет фактические source/config hashes.
Нельзя называть этот source commit существовавшим до development-измерений.

## Что изменено и почему

Ровно одно поле полного Config: `disturbance_limit_mps2`, 0.6 -> 0.7 м/с².
Точный измеренный float **0.7000000000000001** сохранён в JSON/YAML. Физические
F/P/B, adaptation_tau=.5, gain1/holdoff.5, Q/R, guards, Timeline, 20 Hz/delay0 и
масштаб входов прежние. Вызывается тот же GuardedReadoutObserver; новые ветви
runtime, датчики, GNSS, таблицы bag ID, переключение состояния при отказе не добавлены.

Диагностика на известном development-примере 30618_073f08d1 показала насыщение
остаточной поправки при тормозной команде -0.5333. Перед dropout состояние d
у v8 равно +.6, у кандидата +.7. В последнем отсчёте cropped 10-секундного
отказа скорость v8 .544813 м/с, кандидата 1.549560 м/с. Ограничение +.6 мешало
компенсировать несовпадение модели с наблюдавшимся движением. Это **эффективная
модельная ошибка**, а не доказательство реального уклона или неверного тормоза.
Изменение предела позволяет прежней адаптации выучить немного большую поправку
до потери колёс. Оно не узнаёт момент инъекции и не получает reference в runtime.

## Вето и регрессии не скрыты

Из **60 original event** receiver-сравнений: **8 улучшились, 52 точно равны,
0 ухудшились**. Это не 60 независимых поездок. Нет новых индивидуальных
false stops, nonrecoveries, schedule/coverage/causality/reset failures.
Прежние 4 original, 6 low, 2 abrupt, 2 slow неподтверждённых восстановления
сохранены; отсутствие reference не превращено в успешное восстановление.

Low-speed event совпал точно. Abrupt common-mode: -13.1488% на 30618,
-6.1976% в целом. **Slow common-mode ухудшился:** 3.159766271 -> 3.170000309 м/с,
**+0.3239%** в целом; +0.2959% на 30618; +0.3413% на 30639. Все ниже заранее
заданного допуска .5%, но это реальная регрессия и сохраняющийся серьёзный риск.
Абсолютная slow-ошибка порядка 3.17 м/с не выдаётся за решённую общую пробуксовку.

На 30639 clean distance +0.0186%, full distance +0.0065%. Все per-case MAE/p95,
bias, recovery и distance, включая ухудшения, сохранены в полном evidence.
112 тождеств delta_s=integral(delta_v) проверены независимо по NPZ; max error
6.561862164744525e-12 м. Prefault outputs равны собственному clean replay.
Накопленное смещение не сбрасывается после восстановления.

**Групповая концентрация выигрыша:** у 30618 всего две reference-bearing группы.
В 711abb923942f9fe original RMSE .125038907 остаётся прежним. В 8269991eafa82c45
.419757752 -> .289091452 (-31.1290%). Если убрать последнюю группу, выигрыш
исчезает, но не превращается в регрессию. Все группы и leave-one-group-out
сохранены. Переносимость на hidden пока не установлена.

## Фактическая проверка и воспроизводимость

**27 новых +156 исторических runtime +43 integrity =226 test invocations PASS.**
Проверены exact-off, независимая static configuration, YAML/factory parity,
причинность, future/stale/duplicate/reset, bounded state и интеграл выходной v.
Python compileall PASS. Локальный numerical snapshot старый e3b0c9c, поэтому
новые 161 packaging tests main не приписываются этому проходу. Численные pins
main неизменны; опубликованные 11 implementation/freeze blobs совпали с локальными.

Повтор выбранного полного сравнения с 2 workers вместо 4: **17 per-bag JSON,
73 NPZ /146 model arrays /3169674 prediction rows совпали точно**, max difference0.
Summary равен кроме timing. Wall 21.5083/35.2660с — offline replay, не node latency.
Это детерминированная воспроизводимость, не независимая статистическая проверка.

Один round2 replay прерван внешним timeout после 13 сохранённых bags. Повтор
неизменного source завершил 17; все 13 ранних JSON совпали без timing. Оба лога
сохранены. В позднем пассивном trace сначала не сработал exact-float selector
длительности 10с; заменён на tolerance до получения trace. Runtime/scorer не менялись.

**Не выполнены:** train-check, validation, final test, enabled installed ROS,
end-to-end latency/RSS/2CPU500MB и официальный XYZ. Нового CI PASS нет;
[skip ci] не выдаётся за успешную проверку. Нет загруженного официального
pathgraph. Польза sparse GNSS не присваивается этому velocity-кандидату.
Правило «считается 30618» атрибутировано пользовательской сводке организаторов.
