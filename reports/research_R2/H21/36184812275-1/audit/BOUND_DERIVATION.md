# Условная оболочка: что доказано и что не доказано

Пусть v(t)∈[L,U], |v'|≤A, |v|≤V. На шаге h до обработки нового колеса весь возможный velocity tube содержится в [max(-V,L-Ah), min(V,U+Ah)]. Эта оболочка нужна для диапазона нелинейной модели; один midpoint недостаточен.

При u≥0, q≥0 и F,P>0 target = direction*q*min(F,P/max(|v|,1)). Cap невозрастает по |v|. Поэтому extrema вычисляются по minimum/maximum |v| всего tube; если tube пересекает ноль, minimum=0. Для direction=-1 концы переставляются. При u<0 target=-q*B*tanh(v/.2), производная неположительна. При изменении causal held command extrema по u лежат на концах предыдущего/текущего диапазона и в точке 0 при смене знака; unknown/stale использует полный физический target.

R(v)=r*tanh(v/.2)+q_drag*v*|v| монотонно возрастает при r,q_drag≥0: производная r/.2*sech²(v/.2)+2*q_drag*|v|≥0 (в нуле непрерывный предел). Значит min R=R(tube_L), max R=R(tube_U).

Для actuator a'=(target-a)/tau, tau>0, rho=exp(-h/tau)∈(0,1]. При target∈[T_L,T_U] сравнение с постоянными границами даёт a(h)∈[rho*a_L+(1-rho)*T_L, rho*a_U+(1-rho)*T_U]. Hull старого и конечного диапазона охватывает промежуточные моменты шага. Константный target не требуется, но его нахождение в заявленных bounds требуется на всём шаге.

При d∈[-D,D] имеем g∈[a_min-R_max-D,a_max-R_min+D], после монотонного clipping по [-A,A] включение сохраняется. Интегрирование этого диапазона даёт [L+h*g_L,U+h*g_U], затем clipping по [-V,V]. Hull с нулём при возможном пересечении не сужает оболочку. Без новой информации ширина не уменьшается, кроме ограничения глобальными физическими пределами. Малое outward padding в реализации — защита от бытового roundoff, не сертифицированная interval-arithmetic библиотека.

Wolfram вернул False для наличия контрпримера interval affine propagation и velocity increment при заданных inequalities; True для монотонности power cap/сопротивления и clipping. Код и фактические ответы сохранены отдельно.

## Недоказанные эмпирические предпосылки

Начальный anchor от колёс — УСЛОВНО доверенный. 3*wheel_sigma не является доказанной абсолютной границей ошибки и не даёт без распределительных предпосылок вероятности 99.7%. Два колеса могут иметь одинаковый bias; независимого 1/sqrt(2) сужения нет. Параметры сил и D=.6 взяты из фиксированной модели, а не сертифицированы на настоящем трамвае. ZOH/hull предположение не покрывает неизвестные внутритактовые excursions controller вне предыдущего/текущего диапазона. Поэтому математическое включение условной clipped-модели НЕ означает гарантированное включение реальной скорости.

Для x=[v,d,b], v'=d, d'=b'=0, y=v+b матрица наблюдаемости [[1,0,1],[0,1,0],[0,0,0]] имеет ранг2, nullspace span{[-1,0,1]}. Сдвиг v→v+k, b→b-k не меняет y и согласуется с динамикой. H21 не устраняет эту неидентифицируемость. Actual GNSS coverage относится только к внешней диагностике записей; GNSS не попадает в алгоритм.
