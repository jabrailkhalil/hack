## Почему счётчика поправок недостаточно

В исходном потоке Localizer обработал435 fixes: stale14, no_history20,
no_course255, off_map_or_heading51, initialized1, thinned68, corrected6,
route_exhausted20. Следовательно, прежние «шесть коррекций» не означают,
что всей системе было достаточно шести спутниковых сообщений.

Перед первым захватом маршрута курс определяется смещением >=2м между прошлым
и текущим fix в2-секундном окне, разделёнными >=0.3с. При одиночных редких fixes
это окно пусто. На стартовом участке нового bag доступные fixes не обеспечивают
такой захват; более позднего плотного фрагмента после маскирования уже нет.

Отдельный синтетический regression-test показал ту же зависимость даже на
полностью покрытой прямой: при частых fixes привязка есть, при одном fix раз30с
курса нет. Поэтому это не только неполнота конкретной карты. Однако из одного
bag и выбранных фаз нельзя делать статистический вывод обо всех скрытых тестах.

Нулевое покрытие = нет координат, `accuracy_rmse=null`, НЕ нулевая ошибка и НЕ
успех локализации. И при исходном потоке покрытие частичное. Новых XYZ RMSE здесь
нет: эталон вообще не декодируется. Прежние1.34–1.46м остаются корректно заявленным
частичным опытом при фактически записанной последовательности GNSS, но не
подтверждают готовность к гарантированному условиями стартовому GNSS.

## Воспроизведение

Нужны прежний архив Pathgraph и DB из загруженного check-code-with-bag.zip:

```bash
python -m unittest discover -s research/v8_pathgraph -p 'test_*.py' -v
python research/v8_pathgraph/availability_audit.py \
  --bundle /absolute/v8_pathgraph_gnss_20260927.zip \
  --db /absolute/check-code/bags/30618_88aea4d9/30618_88aea4d9_0.db3 \
  --output /absolute/NEW-availability-result
```

Чат уточняет разрешение GNSS и геометрию антенн, но не CRS, высотный datum и
недостающие участки. Источник и необходимые архитектурные изменения перечислены
в research/v8_pathgraph/ORGANIZER_CONTRACT.md. Не превращать сообщение поддержки
«можно» в допущение «всегда придёт». Новая реализация старта должна проверяться
с удалением поздних входов до любого использования и с явным учётом покрытия.
