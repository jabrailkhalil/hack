# Одновременно появившийся PR #11

Во время текущего отбора был открыт [PR #11](https://github.com/jabrailkhalil/hack/pull/11), head `d7bc06016665d51d187d68c8b8c4300264e0f9ea`, ветка `research/timestamp-v6`. Он не существовал в списке открытых PR при исходном чтении main; PR #10 к тому моменту уже был объединён.

Новый PR предлагает причинную компенсацию возраста принятых колёсных измерений плюс добавку process-noise к дисперсии. Это близкая, но не идентичная нашим projection-гипотезам реализация. Его код/описание просмотрены; отдельного повторного прогона его реализации в этом цикле не выполнялось. Приведённые ниже числа — **из отчёта PR #11**, а не новые измерения runner `research/observer-v6`.

| Показатель | v5 | PR #11 |
|---|---:|---:|
| Clean group-macro RMSE, м/с | 0.117138274 | 0.114476684 |
| Fault-event group-macro RMSE, м/с | 0.538434411 | 0.548979449 |
| Scalar span distance RMSE, м | 4.630977808 | 4.577133777 |

Относительно v5: clean улучшение около 2.272%, scalar distance около 1.163%, **fault-регрессия около 1.959%**. Это альтернативный компромисс: он не доминирует v5 по всем рассматриваемым метрикам. Его собственный план допускает до 5% fault-регрессии; наш опубликованный ранее `plan_v6.json` допускает только 0.5%. Эти разные пороги нельзя молча подменять друг другом после получения результатов.

По зафиксированной политике текущего отбора профиль из PR #11 не заменяет активный v5. PR не закрыт, его ветка и материалы не изменены. Для его последующего объединения нужно согласованное решение о допустимом компромиссе, rebase конфликтующих исследовательских путей и новые проверки активной версии. Если приоритетом станет точность обычного движения при допускаемой регрессии faults, выбор может быть другим; универсально лучший профиль не заявляется.

Main переводится с прежнего default v4 на уже проверенный v5 через PR #12. Пять собственных отклонённых гипотез и этот отдельно рассмотренный внешний PR не считаются одним и тем же экспериментом. Ни старые final-test числа v4, ни validation PR #11 не объявляются независимым подтверждением нового профиля.
