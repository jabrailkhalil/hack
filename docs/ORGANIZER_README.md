## Что сообщает источник

README описывает 122 SQLite rosbag2-прогона: 103 с префиксом 30618 и 19 с префиксом 30639. В нём указаны приблизительно 36.7 часа записи, 8.8 миллиона сообщений и 825 МБ после распаковки. Это сводные числа **из источника**, а не результат нашего полного аудита всех сообщений.

Основной контур ограничен тремя топиками:

| Топик | Тип и поле |
|---|---|
| /vehicle/front_bogie_velocity | tram_vehicle_msgs/msg/VelocitySensor: velocity |
| /vehicle/rear_bogie_velocity | tram_vehicle_msgs/msg/VelocitySensor: velocity |
| /vehicle/driver_position_cmd | tram_vehicle_msgs/msg/DriverControllerCommand: position |

В README колесная скорость названа м/с. Контроллер имеет int8: 0 означает нейтраль, +1..+15 тягу, -1..-15 торможение. Оба custom message содержат стандартный Header; сами определения включены в архив.

GNSS master/rover fix имеют тип NavSatFix, master/rover vel - TwistStamped. README отводит им роль эталона и начальной привязки; в скрытых данных GNSS обещан лишь в начале. GNSS/IMU/лидар/камеры в основном контуре запрещены. Offline-калибровка параметров допускается, но конкретный перечень разрешённых обучающих сигналов стоит уточнить.

Выходы заданы строго: `/result/velocity` использует тот же VelocitySensor с полем velocity; `/result/position` использует nav_msgs/msg/Odometry с положением в pose.pose.position. Оценки должны публиковаться во время проигрывания, а не в конце файлом.

README §5.1 описывает синхронизацию судьи по ближайшей временной метке примерно в пределах 50 мс. Stamp должен относиться к времени данных bag, не к часам машины. Судья ожидает метрические x/y/z в локальной системе, согласованной с эталонной траекторией; заявлено сравнение по компонентам и 3D-расстоянию. Подписка судьи best-effort.

## Что не следует молча исправлять

Источник утверждает наличие семи топиков во всех прогонах; наш аудит содержимого отдельных записей обнаружил отсутствие некоторых GNSS-сообщений. Источник называет скорости м/с; измеренное отношение к GNSS близко к 3.6. Требование xyz в README отличается от допуска относительной одометрии в PDF. Это зафиксированные расхождения, а не основание переписать источник под наше решение.

Подробности: [DATA_AUDIT.md](DATA_AUDIT.md), [ORGANIZER_QUESTIONS.md](ORGANIZER_QUESTIONS.md). Ни карта пути, ни её origin не перечислены в составе внешнего архива; наличие готового pathgraph в данных не подтверждено.
