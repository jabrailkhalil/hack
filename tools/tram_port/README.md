# Наши варианты в native-стенде hack

**SYNTHETIC_NATIVE_FIXTURES_ONLY / REAL_DATA_NOT_EVALUATED.** Это офлайн-порт, не замена активной ROS-ноды.

Код перенесён из аудита `tram-hack-native-port-audit.zip`. Вычислительные ядра, параметры, адаптер, входные сценарии и функции оценки сохранены. `run_variant.py` и `variant.json` добавлены только для выбора варианта ветки. Общие зависимости и контрольные модели включены во все ветки; ветки различаются выбранным вариантом и собственными RESULTS/metrics. A/B/C не переобучались. H1 здесь означает H1_10 (перенос времени без физики), H2 — H2_050 (история 0,5 с). D является отдельным модулем геометрии, а не оценивателем скорости.

## Запуск из корня репозитория

В отдельном Python 3.13 окружении Linux (либо WSL):

```bash
python -m pip install -r tools/tram_port/requirements.txt
python tools/tram_port/run_variant.py --output tools/tram_port/runs/fresh
python -m pytest -q tools/tram_port/test_port.py
```

По умолчанию запускаются выбранный вариант, mean и hack v5/v6/v7/v8. Для D выполняется сравнение координат двух заданных полилиний в 802 точках. Для точного полного протокола предыдущего сравнения:

```bash
python tools/tram_port/run_variant.py --all --output tools/tram_port/runs/all-fresh
```

Полный протокол выполняет 19 случаев для 10 методов и сохраняет CSV, подробный JSON, входы и NPZ-трассы. Маска общего времени зависит от состава сравниваемых методов; для воспроизведения исходных paired-метрик использовать `--all`. Существующие выходные каталоги не перезаписываются. Совместимость с Python 3.10/ROS Humble и работа в Windows без WSL не проверены; runner использует POSIX `resource`.

## Результаты и происхождение

`RESULTS.md` и `metrics.csv` относятся к варианту ветки; `COMPARISON.md` содержит краткое сравнение всех моделей. Это экспорт прежних измерений, а не новые реальные испытания. `SOURCES.json` фиксирует исходные коммиты и контрольные суммы архива. Обе стороны используют замороженные конфигурации. `vendor/hack` содержит фиксированное ядро и тестовые зависимости, `vendor/ours` — исполняемые ядра и модель из tram-odometry. Ненужные для этого replay скрипты обучения, старые отдельные train-тесты и большие трассы не копируются в Git: исходный полный архив остаётся источником расширенного аудита; трассы заново создаёт runner.

## Границы

Native Timeline продвигает время по меткам входов, а не по реальным received_ns. Микровыброс между тактами может не попасть в step. Окна с постоянной скоростью благоприятны для удержания последнего значения. В ramp-fixture значение скорости относится к t, хотя stamp=t-25 мс; это проверка поведения кода, не физически согласованный симулятор задержанного датчика. Числа не сопоставимы напрямую с опубликованным реальным GNSS validation hack.

Исходные `src/`, launch, champion, FREEZE, dataset, workflows и старые отчёты репозитория не изменяются. При обычном ROS launch продолжает работать champion v8. Нулевые поля ковариации порта не являются подтверждёнными границами погрешности.
