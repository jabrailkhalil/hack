# Единственный штатный launch

Устанавливается только odometry.launch.py, который запускает guarded_odometry_node с champion_v8.yaml. Остальные launch-файлы в source являются историческими fixtures и не устанавливаются. Их исходный эксперимент воспроизводится на соответствующем старом commit, не на текущем install_main.
