## Hypothesis and controls

H08 changed the quadrature without refitting the physical model; its single candidate was rejected. H16 and H22 showed original-fault gains with distance/safety regressions. H34 asks whether train-only refitting with consistent propagation changes this result. More accurate numerical integration is not necessarily a more accurate real vehicle model.

A = original end-drive Euler velocity prediction, seven-parameter refit. B = H08 analytic held-target drive integral and midpoint resistance, the same seven-parameter refit. B is the ONLY selectable candidate; A is an attribution control, not a second selectable candidate. Same-parameter B0 versus pinned v8 is diagnostic, not a parameter alternative. No command event-time/H32 change, no new deadtime, no command map, no disturbance rule/regularization against distance, no Q/R/gate change.

The held target uses the start-of-tick velocity exactly as H08. For x=dt/tau, mean drive is drive0+(target-drive0)*[1+(expm1(-x)/x)], using the continuous series at tiny x. A half-step integral predicts resistance's midpoint, with existing acceleration/speed clipping. End drive uses expm1. Original sign guard and post-correction trapezoidal distance remain. The B readout receives the very pre-correction effective acceleration used by B propagation, not the old end-drive Euler acceleration. Scalar Joseph/gain reconstruction is unchanged. The readout correction is never fed back to internal v/d. Numerical clipping still limits the method's formal order.

Implementation: opt-in subclass plus explicit isolated patch providing a propagation hook in core and acceleration accessor in guarded_readout. Off dispatches the exact original arithmetic and reproduces full v8 Estimate/internal fields. Canonical files in the research branch stay untouched; apply patch only in experiment copies. No changes to Timeline/scorer or data scheduling. Runtime inputs controller/front/rear only; O(1) extra scalars, no scientific runtime dependencies.
