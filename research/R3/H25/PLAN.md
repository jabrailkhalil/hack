## Математика и бюджет
c_front=c0 exp(delta), c_rear=c0 exp(-delta), c0=1/3.6 неизменен. Product=c0^2, delta_i=.5 log(r/f) при одновременных ненулевых readings одного знака и одинаковой истинной продольной скорости. Общий scale не идентифицируется; slip и timing bias могут объяснить ratio. Sensitivities (-1/(2f),1/(2r)) расходятся у нуля. При малом skew h и ускорении a ложная delta~a*h/(2v). Среднее двух равных readings после ненулевой delta меняется на v(cosh(delta)-1); fixed geometric mean не означает fixed arithmetic mean/истинную скорость.
Ровно ОДНА robust group-balanced оценка и abs(delta)<=.01, без сеток cap/порогов, без per-bag constants. Train check не используется для переоценки delta. Никакого GNSS scale. Ноль/off — контроль, не второй кандидат.
Wolfram выполнит/выполнил algebra checks; worksheet/output/warnings сохраняются. Результат не доказывает устойчивость nonlinear observer или accuracy. По сообщённому в карточке quota stop Consensus/Scite повторно не вызываются и не обходятся. Внешнее основание: abstract первичной работы Jung/Chung 2011 DOI10.5772/50906, авторская документация CVRA по различию wheel ratio и общей длины. Их differential-drive/heading/reference-track процедура НЕ переносится как доказательство для двух тележек; полный текст статьи не заявляется прочитанным.

## Сначала prerequisite на train, до runtime-патча
Все 64 train bag полностью, штатный Store.load(bag,'train'), только controller/front/rear. GNSS train не открывать. Baseline replay выполняется с exact YAML. Source/profile/scorer/loader/split hashes проверяются против v8. Для каждого train bag отдельно сравнить original evaluate.replay baseline с инструментированным сборщиком, который наследует v8 и только читает состояние после step: точные outputs включая Estimate.v/s и runtime counters, NaN wheel columns сравнивать equal_nan. Это проверка driver, не reference accuracy.
Пары берутся лишь на такте FUSED с двумя ACCEPTED, свежей валидной командой, возраста обоих samples<=.10s, skew<=.025s, одинаковым ненулевым знаком, 2<=abs(f),abs(r)<=30 m/s. Каждый sample в выбранной паре новый; оба stamps строго растут. Предыдущее FUSED наблюдение задаёт backward derivatives отдельно для front/rear, dt каждого от .05 до .25s; abs(derivative)<=.20 m/s^2 для ОБОИХ. Это только прошлые данные, без interpolation/projection/future. Предыдущее наблюдение обновляется и при не прошедшем slow-rate predicate, чтобы не выбирать удобный long baseline.
Любой статус кроме ACCEPTED/DUPLICATE_OR_OLD сбрасывает good history и блокирует пары на .50s. Непрерывное выполнение остальных условий>=.50s необходимо до регистрации ratios; prediction-only duplicate ticks не добавляют observations, разрыв FUSED-пар>.25s обрывает выдержку. Original invalid/range/rate/zero-lock/quarantine guards сохраняются. Extra small difference filter по целевой delta не добавляется. Все исключения/counts сохраняются.
Группы — существующие связанные group IDs. Для оценивания bag median нужно>=30 eligible pairs, для квалифицированной группы>=100 eligible pairs после исключения точных vehicle_wire_sha256 дубликатов (лексикографически первый bag, остальные всё равно replay/диагностируются). Group value=median bag medians; estimator=median fitting-group values. Всего 27 train groups, назначение ДО данных: sorted unique group IDs, индексы i%3==0 — check (9), остальные fit (18). Ни группы, ни bags по результатам не отбираются, кроме записанных minimum-count conditions.
Дополнительные заранее заданные срезы: |v| bins [2,5),[5,10),[10,20),[20,30]; traction/coast/brake по valid command и прежнему deadband; знак движения. Для среза требуется>=100 selected pairs в каждой из>=3 групп; его balanced median сравнивается с frozen delta, не переобучает её. Сохранить все срезы, включая недостаточно покрытые.

### Предварительный stop-rule (до полного development)
Coverage PASS: >=8 qualified groups, >=5 fit и>=3 check, >=1000 selected уникальных pairs. Иначе INCONCLUSIVE/INSUFFICIENT_TRAIN_COVERAGE, дальше не идти.
Одно delta_raw=median fit group values; delta=clip(delta_raw,+/-.01). Тайминговый описательный bound B=median по fit groups их median(max backward |a| * skew / (2 min(|f|,|r|))); это не rigorous CI. Minimum effect epsilon=max(.0001,2B). Если abs(delta)<=epsilon: INCONCLUSIVE/NO_RESOLVED_RELATIVE_MISMATCH, не считать доказательством нулевой эффективности всего семейства.
Если abs(delta_raw)>.01: REJECTED/OUTSIDE_PREREGISTERED_CAP; не пробовать иной cap.
Stability: не менее80% квалифицированных fit и отдельно check groups должны иметь тот же ненулевой знак, что delta; не менее80% каждой группы ролей должны удовлетворять abs(group_delta-delta)<=max(.0005,.5abs(delta)); 90%-10% spread всех group medians<=max(.002,abs(delta)). Любой провал -> INCONCLUSIVE/GROUP_UNSTABLE; не объявлять slip установленной причиной.
Каждый покрытый speed/mode/sign slice должен иметь тот же знак и abs(slice_delta-delta)<=max(.0005,.5abs(delta)); иначе INCONCLUSIVE/REGIME_DEPENDENT. Если нет покрытых >=2 speed bins и>=2 command regimes — INCONCLUSIVE/INSUFFICIENT_REGIME_COVERAGE. Constant delta не переносить между режимами без основания.
Только если coverage/effect/stability PASS: на check groups сравнить mean по groups median |delta_i-delta| с mean median |delta_i|; должно уменьшиться>=10%, и не более20% check groups могут вырасти>max(.0001,5% исходного). Иначе REJECTED/RELATIVE_FIT_NOT_TRANSFERABLE. Это wheel-proxy admission, не odometry truth. Любой stop значит development/validation NOT_RUN_AFTER_PREREQUISITE; source диагностики и фактическое delta сохраняются, включённого runtime candidate/accuracy SHA может не быть.

## Условный минимальный runtime-кандидат только после prerequisite PASS
Одно frozen train delta, не refit на check/development. Реализовать relative scale после исходной c0 конверсии и temporal admission, до fusion/adaptation/readout. Сырые invalid/range/rate проверки выполняются в исходных единицах c0 независимо от corrected checks; уже недопустимый raw input не допускается за счёт уменьшения scale. Corrected value также проходит range/rate gates. Оригинальные source stamps, command, zero-lock/quarantine, timeline и guards не ослаблять. В реализации явно отделить raw history от calibrated history, максимум два bounded previous samples на канал. Обе held-проверки/readout и core получают согласованные calibrated значения после raw admission. Не создавать future wait, не менять scorer input injections/order. Disabled delta0 коротким путём возвращает точный canonical v8, все поля/выходы/статусы/счётчики. Возможные изменения initialization schedule считаются fail, не корректируются в evaluator.
До данных candidate: build/unit, feature-off full equality, causal prefix, signs, zero/nearzero, invalid NaN/inf/range (including raw40.1 scaled below40), raw rate violation scaled below limit, duplicates/future/stale/reset, product/bounds, both locks/quarantine/recovery, mean-speed counterexample, synthetic coherent slip nonidentifiability. Положительная синтетика не доказывает improvement.

## Development/validation contract (только после train PASS)
Все 17 development bags/7 groups, настоящая read-only development role, reference только внешнему evaluator. Оригинальные score/replay/masks/timestamps/aggregation неизменны; только factory. Original four fault windows из baseline; original metrics отдельно от диагностик. Coverage runtime: >=1000 реально изменённых accepted samples в>=3 исходных development groups и изменение returned v>1e-8 на>=100 ticks в>=3 groups. Не путать вычисленные multipliers с вмешательством.
R3 gate ДО validation: >=2% clean macro gain ИЛИ >=5% original fault macro gain; clean/fault/pooled regression<=.5%, scalar distance<=1%; per-bag clean<=base+max(.005m/s,5%base); exact n/masks/coverage/schedule, без новых per-case false stops/unrecovered/causal/reset. Порог baseline0: абсолютный1e-12 вместо деления. Guard suites: existing low-speed lock и H11 abrupt common-mode на development, event-macro regression<=.5%, без новых false stops/unrecovered. Отдельная предзаданная single-channel +/-5m/s 5s bias suite на original anchors для front/rear; max per-sign event-macro regression<=.5%, без safety нарушений. Если suite/reference/activation отсутствует — INCONCLUSIVE, не пропускать veto. Любой численный fail -> REJECTED, validation не открывать.
После PASS — отдельный FREEZE source/config/evaluator/data/split/PLAN/dev result hashes и commit/push до первого validation IO; затем один full paired validation19 bags/76original faults. После результатов без tuning. Старый reused validation не независимый final test; final/test measurements не открывать.
