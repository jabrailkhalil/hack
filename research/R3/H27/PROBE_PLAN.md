## Data and prospective rules
All64 original train bags, vehicle topics only, full replay. Train groups partitioned by sorted group IDs: alternating groups fit/check, even-index groups fit. No train GNSS. All17 original development bags, natural streams and exactly original fault placement/bias5/dropout5/dropout10/lock3. No validation/test load in the probe, and no reference is needed for it. Role and SHA256 checked before SQLite read. Standard source-time replay unchanged; no fault flags enter observer.

Observer-only monitor keeps at most16 trusted legacy d snapshots in a1.0s TTL. Snapshot time is when d became available (output t), not a backdated pair stamp. Snapshot requires an actual legacy eligible derivative update: FUSED, current command fresh, new two-wheel pair with dt in[.05,max_age], |measured_a|<=max_accel, |z|>.5. Additional trust: both wheels accepted, individual age<=.20s, skew<=.05s, wheel difference<=.15m/s. No duplicate/old/future samples recorded. Controller mode is sign outside native deadband; invalid/mode change clears history. Hard rejection clears history only after entry diagnostics have been captured. Unchanged MODEL_ONLY ticks with duplicate held samples are NOT a new outage.

A loss episode begins causally after native step when mode=MODEL_ONLY, no accepted wheels, at least one status !=DUPLICATE_OR_OLD. It ends on FUSED/SINGLE_WHEEL/REACQUIRING/STOPPED, invalid controller, or command mode change. Duplicate-only prediction ticks continue an already established loss. No known future fault onset, duration or kind is used.

Only two lags: .2/.4s. At entry, last trusted history sample must be<=.35s old. Checkpoint=median d of samples in[last_trusted_time-lag-.2,last_trusted_time-lag], at least3 points spanning>=.10s. Same rule for both. Stability: median absolute deviation<=threshold/2. Current native d differs from checkpoint by>threshold. A proposal is not an intervention: this stage only counts and retains history/onset/end/mode traces.

Threshold, acceleration units: theta=max(.02,3*median(group_sigma)), group_sigma=1.4826*median(|r-median(r)|), r=d_k-d_(k-1) for consecutive trusted, same-mode updates separated by .05..max_age. These are residual increments of the legacy EMA state, a wheel-derived diagnostic proxy, NOT true acceleration errors. Use fit-train groups with>=100 residuals; require>=3 such groups. Keep check-train distributions separate. No threshold tuning or bag-specific adjustment; publish fitted value before development probe.

Prospective foundation coverage for each lag on all development natural+original fault episodes: >=10 qualifying entry episodes in>=3 original source groups AND>=100 eligible model-only ticks with proposed nonzero d difference. Receiver pairs/ticks/repeated faults on one bag are not independent groups. Insufficient coverage => INCONCLUSIVE and no validation. A sufficient count permits a minimal patch and a PLAN before candidate accuracy comparisons; it does not prove a defect or a gain.
