## Фиксированная оценка решётки
Все64 train bag, только три vehicle topics; SHA256 каждого DB и исходного split. Считать новые измерения по строго возрастающему source stamp канала, а не изменениям значения. Равные values при новых stamps учитывать отдельно, но не использовать постоянную скорость/нули как доказательство решётки. Payload — исходный CDR float64, без CSV/округления. Масштаб 1/3.6 неизменен.

27 train групп сортируются по ID; индексы i%3==2 образуют check (9), остальные fitting (18). Внутригрупповые wire-дубликаты исключаются из fitting/statistics, но все64 читаются/проверяются. Решётка оценивается только по fitting; check не выбирает q и не сдвигает его.

Основной subset: finite .1<=abs(v)<=40; текущая/последняя causal controller sample свежая<=.5s и abs(u)<=1; предыдущий wheel source interval 0<dt<=.25 и abs(v-v_prev)>1e-9. Это разные source samples на меняющемся движении. Никакого GNSS или подбора по accuracy. Квалифицированная группа: >=1000 таких samples, >=100 различных значений, span>=1m/s. Требуется >=8 fit и >=4 check групп на каждый канал; отдельно traction u>.04, brake u<-.04, coast иначе: >=300 samples в >=3 группах на режим. Недостаточность coverage — INCONCLUSIVE.

Один offline estimator, не runtime grid: q в [1e-6,.5]m/s, shift в [0,q). Из fitting-only уникальных sorted levels берутся adjacent gaps: 64 наиболее частых gaps (округление только предложений до10 significant digits) и 101 равномерная quantile gaps; делители1..32. Также фиксированная сетка предложений {1,2,2.5,5}*10^k, k=-6..0, в SI и исходных единицах/3.6. Предложения вне диапазона удаляются; при >8192 оставить8192 равномерно по sorted index. Для поиска максимум2048 равномерных source-index samples на fitting группу, одинаковый вес групп.

Начальный shift — circular mean exp(2*pi*i*v/q); coherence>=.975. Уточнение q/shift ровно3 trimming+OLS шага по целым bin indices, текущий residual<=.02q, положительный q в исходном диапазоне. Затем проверка на ВСЕХ eligible fitting samples/режимах. Inlier: distance(v,shift+q*Z)<=max(1e-10,.001q). Требуется>=99% в >=80% квалифицированных fitting групп, group-balanced доля>=99%; все три режима>=99% при достаточном coverage. Выбирается наибольший прошедший q только по fitting. После фиксации единственного q/shift check проверяется один раз теми же порогами, без refit. Если никакого q нет — LATTICE_NOT_ESTABLISHED/INCONCLUSIVE. Сдвиг и групповая устойчивость раскрываются, а не подгоняются на check.

Практический порог ДО измерений: q^2/(12*sigma_w^2)>=.01, sigma_w=.1m/s, то есть q>=sqrt(.0012)=.03464101615137755m/s. Это консервативный effect floor для данного проекта, не теорема accuracy. Микроскопическая решётка — NO_PRACTICAL_SIGNAL/INCONCLUSIVE, не REJECTED.

Дополнительный shift-invariant диагностический верхний предел для практического диапазона q=[sqrt(.0012),.5]: для каждой группы до512 disjoint consecutive eligible pairs (равномерно по source index; оба samples входят только в одну пару) вычислить максимум fraction с distance(delta,q*Z)<=.002q+2e-10 по всему непрерывному q range точным sweep интервалов [d/(n+.002),d/(n-.002)] с allowance2e-10. Этот necessary-condition тест не выбирает q. Если исходная выбранная пара значений оба inliers, разность обязана пройти. Требование для этой заранее заданной audit-выборки: >=98% пар в >=80% qualified fit/check группах. Это проверка sampled subset, не probabilistic certificate всех будущих данных.

## Единственный условный runtime candidate
Только при lattice/coverage/effect PASS обоих каналов — один интервальный кандидат. Prior x~N(mu,P), аналоговое y=x+noise, R=прежняя residual-scaled correlated floor (не вычитать q^2/12). Наблюдение y в [z-q/2,z+q/2]. S=P+R, a=(lower-mu)/sqrt(S), b=(upper-mu)/sqrt(S), Z=Phi(b)-Phi(a), lambda=(phi(a)-phi(b))/Z, Vt=1+(a*phi(a)-b*phi(b))/Z-lambda^2. mean=mu+P/sqrt(S)*lambda; Ppost=P-P^2/S*(1-Vt). Readout использует frozen-R локальную чувствительность K_eff=P/S*(1-Vt), не gain по posthoc отношению residual и не новый noise fit. Gaussian approximation дальше не считается exact posterior всего switched observer.

Для пары один общий интервал среднего, q_pair=(q_front+q_rear)/2, один прежний R floor, НЕ произведение независимых likelihood. Raw samples/gates/adaptation/stop/zero-lock/quarantine неизменны. Разрешён только isolated core update hook+actual gain в isolated readout; default/Timeline/ROS interfaces не менять. Никакого ad-hoc speed deadband. Finite-tail fallback к baseline Gaussian update, счётчик fallback. q->0/off exact tests, analytic/numeric moment checks, PSD/tails, начало движения/остановка/lock, prefix/stale/duplicates/reset. Нет GNSS/IMU/oracles, O(1), stdlib runtime.

До development accuracy дополнительно нужен median relative Ppost difference>=1% на >=1000 accepted train updates в >=4 check группах с fixed q; иначе NO_PRACTICAL_POSTERIOR_EFFECT. Это пассивный one-step diagnostic, не fit. Activation development: >=1000 output changes abs(delta_v)>=.001m/s в >=3 группах. Синтетика отдельно, не accuracy evidence.
