## One fixed candidate, no fitting/sweep

State [v,A], A=drive_a. Legacy d is a separate causal input with the same clipped learning rule; joint innovation never directly corrects d. Same force/power/brake/roll/drag/tau/units and mean integration as v8.

One engineering prior, specified without GNSS or residual fitting: S_A=(disturbance_limit/2)^2=.09 (m/s^2)^2, P_AA at reset=S_A, P_vA=0. With rho=exp(-h/tau), actuator process variance q_step=S_A*(1-rho^2) (equivalent continuous intensity 2*S_A/tau). Coupled end-step actuator noise enters with L=[h*s_v*s_a,1], Q_A=q_step*L*L^T. Velocity noise remains legacy process_noise_v*h*(4 if command stale else 1), plus h^2*(disturbance_limit/2)^2 to represent unmodelled d error. This last allowance assumes step-local zero-mean d error; it is NOT a guaranteed bound for a persistent biased d or common wheel bias. No calibrated confidence claim. Only this Q_A/P_A pair is tested on recordings; optional synthetic scaling .5/2 only checks numerical bounds and is not a model-selection exercise.

Prediction is P-=F P F^T+Q with the Jacobian of the actual drive-before-Euler scheme. Away from switching boundaries, A'=rho*A+(1-rho)*T(u,v), F_Av=(1-rho)*T_v, F_AA=rho, F_vv=s_v*[1+h*s_a*(F_Av-R_v)], F_vA=s_v*h*s_a*rho. Saturated acceleration/speed use their active derivative; no-reversal projection sets the velocity row to zero. Nondifferentiable exact boundaries are explicitly excluded from two-sided finite-difference tests and tested by one-sided/branch cases. The frozen-target, constant-resistance special case is [[1,h*rho],[0,rho]], observability det=h*rho; this is not joint observability of arbitrary d and common bias.

Use original robust R and H=[1,0]. Kv=Pvv-/S; Ka=PvA-/S only on a new accepted FUSED pair satisfying the trusted limits above, outside common quarantine. Otherwise Ka=0. All existing raw/model/rate/zero-lock/reacquisition/quarantine guards remain. A update is limited to the global physical drive-target envelope; when limited, the effective applied Ka=delta_A/residual is used in the full Joseph update, not the unclipped gain. Constrained Ka=0 also uses full Joseph. P remains a symmetric 2x2 represented by three scalars. Bootstrap and STOPPED reset actuator covariance/cross term, without changing legacy mean resets. Numerically enforce nonnegative diagonal floors and PSD correlation; bound diagonals by physical squared envelopes using congruent scaling when needed. These covariance safeguards are approximate, not probabilistic guarantees.

Readout MUST receive the actual prediction variance, Kv and pre-correction a_model. It must not infer Kv from old_pv+Q*h or recompute acceleration using the innovation-corrected actuator. Core/readout hooks exist only in an isolated candidate package/explicit patch; disabled hooks reproduce all canonical fields and outputs exactly.
