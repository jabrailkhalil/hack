# R5-H45 — план до fitting и измерения кандидатов

Baseline b2783206000091ab11a1c11ac3ff79082188a4fb, tree 973d50d288e050325ee1c71a90fa8d81f2a099af; полный GuardedReadoutObserver/champion_v8.yaml. Ветка research/R5-H45. H35 не продолжается.

## Основание и область
H25 не смог обосновать единую относительную front/rear поправку по wheel-only train. H45 проверяет другую возможность: остаточный общий или поканальный multiplicative bias после правильного перевода км/ч в м/с. Q&A подтверждает км/ч для колёс; 1/3.6 фиксируется как единицы, не fitted scale. Teacher H42 — только offline среднее модулей GNSS speed, не signed longitudinal ground truth. Общая систематическая ошибка GNSS и общий slip могут быть неотличимы от остаточной шкалы.

Runtime: неизменный перевод единиц до Timeline; два положительных постоянных множителя cf/cr в [0.97,1.03] внутри исследовательского subclass. Controller, stamps, Timeline, scorer, физика, Kalman R/gain, readout, stop/recovery и H11 остаются каноническими. Raw invalid/range/rate/duplicate gates нельзя обойти уменьшением значения: сначала исходный raw gate, затем тот же gate на скорректированном потоке. Raw RATE_ANOMALY сохраняет quarantine. Корректированные held values используются согласованно core и readout. Нет offsets, GNSS/IMU, bag IDs, fault oracle, online learning либо нового waiting. Дополнительная память ограничена состоянием raw wheel gates; это не второй фильтр движения. Disabled и cf=cr=1 обязаны точно воспроизводить все исходные поля/Estimate/counters.

## Жёсткая зависимость
До любого real-data fitting или сравнения калиброванных кандидатов обязательны два точных producer ZIP, transport verification, оба native verifier, folds bridge и новый DEPENDENCIES.lock.json. Pins берутся из R5 wave2 DEPENDENCIES.expected.json без изменения. Receipt/PR/отчёт не заменяет manifest/NPZ. При недоступности bytes: DEPENDENCY_PENDING / scientific NOT_EVALUATED, не REJECTED; запрещено пересоздавать H42/H43. Разрешены source verification, math, интерфейсы, synthetic/unit/integrity tests, hash датасета; payload DB до разрешения зависимости не открывать.

## Конечный бюджет будущего fitting
Ровно две структуры, не две сетки: A — один общий c; B — cf/cr с одним фиксированным prior к общему c структуры A. Диапазон каждого [0.97,1.03]. По одному robust fit каждой структуры на исходных 20 fit groups, check — исходные 7 groups; wire duplicates имеют один вес. Никаких fitted parameters соседних H44/H46. Loss — group-balanced Huber по средним скоростям на неперекрывающихся интервалах 1 s, Huber scale 0.10 m/s. У B дополнительный penalty 0.5*((cf-cA)/0.01)^2 + 0.5*((cr-cA)/0.01)^2, без подбора силы. Один старт identity для A, cA для B, analytic gradient; не более 200 objective calls на структуру, без restarts. Fitting пока не реализован и не запускался: сначала подтвердить фактический schema/timestamp contract teacher по полному payload, не угадать его по receipt.

Interval target — только accepted frozen teacher, без переочистки. Требуются полностью покрытые интервалы; никакой интерполяции через reject или GNSS gap >0.20 s. Источник знака не teacher: сопоставляется модуль wheel displacement; интервалы с wheel sign change исключаются до просмотра candidate error. Временная привязка только документированные source stamps H42; отсутствие её проверяемого соответствия vehicle stamps блокирует fit. Canonical evaluator никогда не использует эти train interval masks.

Check правило: group-balanced Huber minimum из A/B, tie <=1e-12 выбирает A; ни один должен ухудшать identity check loss. До development нужны >=8 fit и >=3 check групп с интервалами, оба metadata labels в каждой роли, >=1000 fit и >=200 check интервалов; общая шкала не объявляется аппаратной. По группам/labels/режимам сохранить loss, масштабы данных, signed residual и leave-one-group-out sensitivity без рефита/удаления групп. Покрытие reverse/start/stop показывать отдельно, отсутствие не заменять synthetic accuracy.

## Допуск L, затем один validation
Все 17 development bags и исходные fault anchors, прежние маски обоих receivers, group macro и Estimate.v/s. Baseline измерять заново, не копировать fingerprint. Нужен >=2% clean gain ИЛИ >=5% original fault gain; clean/fault/pooled <=0.5% regression; clean/full-faulted-bag distance <=1%; clean per-bag <=base+max(0.005m/s,5%base). Без новых false stops, individual unrecovered, coverage/schedule/causality/reset нарушений. Low-speed/H11 event regression <=0.5% и без новых safety failures. Реально изменённые outputs должны быть в >=3 source groups с reference. Full original faulted bags, delta_s через 10s и terminal, signed bias/MAE/p95/recovery и все локальные регрессии обязательны. Atlas — development diagnostic, не supervised fitting target. При провале development validation не открывать. При успехе — один опубликованный source/config/data/dependency freeze до validation. Reused validation не independent test; final/test запрещён.

## Текущий исполнимый этап и тесты
Первый source/interface checkpoint не содержит fitted calibration.json, выбранного кандидата или accuracy claims. Synthetic factors — только fixtures, не кандидаты для реального выбора. Проверить baseline unit/integrity; disabled и identity exact; свежие/stale/future/duplicate/range/rate входы; raw downscale не спасает invalid; corrected upscale тоже проверяется; H11/zero-lock/recovery; start/stop/reverse; prefix causality; bounded memory; согласованность интеграла и сохранение delta_s после возврата колёс. Математика: положительность/zero/sign invariants, масштабирование интеграла, weighted scalar optimum, неидентифицируемость GNSS common bias. Никакой accuracy по synthetic fixtures.
