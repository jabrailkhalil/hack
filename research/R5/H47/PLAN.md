## One structure and exactly eight causal features
A single shared channel-permutation-equivariant logistic model; no channel-ID coefficient. For each newly received wheel sample at output t, before updating its own feature history:
1 own age / max_age_s;
2 other wheel age / max_age_s;
3 absolute pair skew / pair_skew_s;
4 abs(backward own wheel acceleration - native pre-correction model acceleration) / wheel_rate_limit_mps2;
5 abs(own wheel speed - native predicted velocity) / innovation_floor_mps;
6 absolute front-rear difference / disagreement_mps;
7 current fresh command mode (-1 braking, 0 deadband/coast, +1 traction);
8 mean of PRIOR own absolute model innovations / innovation_floor_mps.
No learned normalization; scales are exact fixed baseline parameters. Each channel has at most 16 innovation records within the last 1 s of availability time, one previous raw sample and one monotonic source watermark. Held/duplicate/old/future/nonfinite samples do not append records or replace the previous raw sample. Histories prune on every successful tick. Missing histories are abstention, not zero. Need >=3 prior records spanning >=.1 s and a previous raw sample at positive interval <=max_age_s; history excludes the current sample. Features are ready only when native mode=FUSED with both wheels ACCEPTED, current command and both samples strictly not future and fresh, |native predicted v|>=1 m/s, and both sample signs agree with it. Bootstrap/stop/reset clear auxiliary state without modifying native state; command loss never gets extended by a history.

Fixed feature domains: features1/2/3 in [0,1], rate innovation in [0,2], model innovation and history mean in [0,4], pair mismatch in [0,1], command in {-1,0,1}. Outside-domain/nonfinite/incomplete pair => abstain and native baseline fallback, not feature clipping. A passive probe can export ready/not-ready rows now, but does NOT predict reliability, alter weights, or certify real example coverage. It accepts only the native step(t,command,front,rear) interface and returns the exact native Estimate.
