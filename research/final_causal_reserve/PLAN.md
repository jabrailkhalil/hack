## Exactly one design
Run unmodified complete main v8 and one independent complete observer with the frozen G configuration on the same causal command/front/rear stream. The main observer's inherited numerical state is never changed by the reserve or output correction. G changes only original torque/power/brake parameters, with F/m=1.288533438861773, P/m=10.72819314542046, B/m=0.8221194868508274 in SI; all other fields match the complete champion_v8 profile. These numbers are fixed before this design's replay, not refitted.

Trust a held wheel pair iff both samples are finite, fresh and in range by existing main checks, their skew/disagreement meet existing main bounds, both main statuses are ACCEPTED or DUPLICATE_OR_OLD, and main is not REACQUIRING. Initialization/waiting, STOPPED or stale command never receive a reserve correction. Use only runtime observations, never injected-fault boundaries, reference, teacher mask, bag identity or future samples.

At the first mistrusted tick, anchor the previous published shadow-minus-main velocity difference. During that episode use delta=(shadow_current-main_current)-anchor. Healthy wheels, STOPPED or stale command end the episode and set delta to zero immediately. No smoothing, learned weights, alternate gates or search. Clip main+delta to existing max_speed and disallow introducing zero/sign reversal relative to main (as in original readout); no additional tuned thresholds. Delta is integrated with the trapezoidal rule on every output step. Accumulated delta_s is NEVER erased on recovery. Output acceleration is main.a plus delta difference/dt. Add conservative delta-squared and integral-absolute-delta envelopes to variance; these are not calibrated confidence intervals.

Two bounded observer states and O(1) episode/integral fields; no scientific runtime imports. Disabled operation and an identical shadow must reproduce original Estimate exactly. Test finite/range/stale/duplicate/future/reset, core-state isolation, prefix causality, stop/sign, integral consistency and retained distance after recovery. This is a runtime-cost increase and must be measured, not called free.
