Исходная версия: 6e6c0e231e34c87d82c7e114ac82acea96fbab1a (калибровка v3).
Запрос владельца: «доделай для финальной сдачи»; промежуточные результаты также сохранять в GitHub.

## Протокол до доступа к final test

1. Аудит runtime, особенно разные частоты датчиков, повторный захват, timestamps, пропуски, непрерывность s, диагностика.
2. Исправления воспроизводимых программных дефектов. Fitted-параметры balanced_physics и масштаб 1/3.6 не подбирать заново. Проверить на unit/development/validation, final test не открывать.
3. Заморозить исходники, параметры, список 22 test-bag и evaluator; сохранить SHA256. Затем один final-test запуск с baseline_v2 и frozen calibrated solution. Сохранять все bag/receiver, coverage и отсутствующий эталон; не менять модель по результату test.
4. Реальная ROS Humble сборка и длительный replay development-bag без сети при 2 CPU / 512 MiB, отдельно wall-time latency, source-age, frequency, RSS/CPU. Прогон в ускоренном темпе не называть проверкой задержки в реальном времени.
5. Сформировать самостоятельный ZIP, команды проверки, поля формы платформы, таблицы метрик, допущения, демонстрационный сценарий и известные ограничения. Проверить сборку именно из ZIP.

## Неизменяемые ограничения

В Issue #1 нет ответа организатора по состоянию начала финализации. Нет подтверждённой карты пути/origin и исправления единиц входной скорости. Поэтому базовая сдача — относительная одометрия (s,0,0), прямо допускаемая PDF при отсутствии абсолютной привязки. Не называть её восстановленной GNSS/ENU xyz-траекторией. В README архива иной xyz-контракт; противоречие оставить явно видимым.

GNSS используется evaluator-only. Опциональный known-route режим не подменять извлечением будущей test GNSS-траектории. Существующий v3 split сохранить. Измерения test не добавлять в обучающий набор.

Результаты и checkpoint-коммиты сохраняются в этой feature-ветке. Слияние только после проверок. Приватность, права доступа и отправку формы хакатона этот процесс не изменяет. Финальный статус должен различать реализованное, измеренное и не подтверждённое организатором.
