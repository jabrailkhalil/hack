# Допущения и параметры

Штатный профиль — [champion_v8.yaml](../src/reserve_odometry/config/champion_v8.yaml). Физические коэффициенты эффективные: масса, радиус, передача и КПД задают параметризацию, а не набор независимо измеренных паспортных величин.

## Начальное состояние и координаты

Начальный путь равен нулю. Начальная скорость оценивается по свежей согласованной паре колёс; до этого результаты не публикуются. Отдельных ROS-параметров `initial_x`, `initial_y`, `initial_z` и `initial_velocity` в текущей ноде нет.

Дополнительные параметры ноды: `route_csv=''` (без карты), `route_s0=0.0` м, `route_frame='map'`. CSV маршрута содержит упорядоченные столбцы `x,y,z` в метрах (`z` можно опустить). `route_s0` задаёт стартовую координату вдоль маршрута. За пределами карты публикация позиции приостанавливается, диагностика сообщает `OUTSIDE_AUTHORIZED_ROUTE`.

Параметры ноды: `rate_hz=20`, `alignment_delay_s=0`, `clock_mode=input_stamp`, `front_scale=rear_scale=1/3.6`. Параметры выходной коррекции: `readout.gain=1`, `readout.holdoff_s=0.5`. Необязательный `trace_timing=false` включает `/result/timing` при значении `true`.

Для изменения параметров скопировать штатный YAML, сохранить корень `reserve_odometry.ros__parameters` и передать путь:

```bash
ros2 launch reserve_odometry odometry.launch.py params_file:=/absolute/path/custom.yaml
```

Для часов rosbag задать в этой копии `clock_mode: ros_clock` и запустить launch с `use_sim_time:=true`.

## Допущения

- Основная динамика продольная; без маршрута абсолютная геометрия не восстанавливается.
- Коэффициент `1/3.6` установлен по данным, несмотря на указание м/с в README организатора. Для входов в м/с следует использовать `1.0`.
- Отрицательная команда — тормоз, направление движения задаётся отдельно.
- Почти нулевое квадратичное сопротивление — результат идентификации, а не утверждение об отсутствии аэродинамики.
- Согласованная ошибка обоих колёс может остаться неразличимой; подробности и план развития — [LIMITATIONS.md](LIMITATIONS.md).
