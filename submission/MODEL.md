# Математическая модель v8

## Входы, состояние и выходы

Входы: положение контроллера `p ∈ [−15,15]`, скорости передней и задней тележек. Нормированная команда `u=p/15`; отрицательная команда задаёт торможение. Скорости приводятся к м/с с помощью `front_scale` и `rear_scale`.

Состояние: скорость `v`, путь `s`, ускорение привода `a_drive`, оценка суммарного возмущения `d` и дисперсия скорости `P`. Выходы: оценка скорости и относительная одометрия. В рабочем расчёте GNSS и IMU не используются.

## 1. Контроллер, момент и сила

Нелинейная характеристика контроллера:

```text
q(u) = clip((|u| − u₀)/(1 − u₀), 0, 1)^γ
Fтяга = direction · q(u) · min(η · i · Tmax / r, Pmax / max(|v|, 1))
Fторм = −q(u) · Bmax · tanh(v / 0.2)
```

Для `u≥0` используется тяговая ветвь, для `u<0` — тормозная. `Tmax` — эффективный суммарный момент двигателя, `i` — передаточное отношение, `η` — КПД, `r` — радиус колеса. Переход от момента к ускорению: `a=η·i·T/(r·m)`. Ограничение мощности уменьшает доступную силу при высокой скорости.

Инерция привода моделируется первым порядком:

```text
α = 1 − exp(−Δt/τ)
a_drive ← a_drive + α · (F/m − a_drive)
```

## 2. Продольная динамика

```text
R(v) = Rroll · tanh(v/0.2) + Rquad · v · |v|
a_model = clip(a_drive − R(v)/m + d, −amax, amax)
v_prior = clip(v + Δt · a_model, −vmax, vmax)
P_prior = P + Qv · Δt
```

Для устаревшей команды процессный шум увеличивается. Суммарное возмущение `d` учитывает несоответствие модели фактическим условиям движения; масса, уклон и сцепление независимо не оцениваются. При торможении и выбеге численный переход через ноль ограничивается, чтобы не создавать самопроизвольный разворот.

## 3. Проверка колёс и коррекция

Проверяются конечность и диапазон значений, возраст, порядок меток времени, производная скорости, согласованность тележек и отклонение от прогноза. Одно измерение используется для коррекции один раз. Допустимое расхождение тележек — 0.7 м/с; скачок проверяется относительно `4·Δt + 0.25` м/с.

Для принятого измерения `z` выполняется скалярная коррекция:

```text
K = P_prior / (P_prior + R)
v ← v_prior + K · (z − v_prior)
P ← (1−K)² · P_prior + K² · R
```

`z` — принятый канал или среднее двух принятых каналов. Большой остаток увеличивает шум измерения `R`. При непригодности обоих каналов используется прогноз модели.

После устойчивого рассогласования повторное сближение с согласованной парой колёс разрешается после выдержки 0.8 с и ограничивается шагом до 0.15 м/с на новую пару с интервалом 0.1 с. После почти одновременного неправдоподобного скачка обоих каналов такой захват блокируется на 1.5 с. Нулевые показания колёс при движущейся модели не вызывают мгновенную остановку.

## 4. Адаптация

По двум новым согласованным колёсным измерениям оценивается ускорение `a_wheels`. Целевое возмущение:

```text
d_target = a_wheels − a_drive + R(v)/m
d ← clip(d + β · (d_target − d), −0.6, 0.6)
β = 1 − exp(−Δt_pair / 0.5)
```

При аномалиях и повторном захвате адаптация приостанавливается. Подтверждённая остановка требует малых свежих показаний обоих колёс, малой модельной скорости, отсутствия тяги и выдержки 0.5 с.

## 5. Компенсация возраста измерения

В v8 публикуемая скорость дополнительно корректируется с учётом возраста принятых измерений `h`:

```text
δv ← (1−K) · δv + K · gain · a_model · h
v_out = clip(v + δv, −vmax, vmax)
```

Коррекция действует при свежих согласованных показаниях обоих каналов и свежей команде. При нарушении этих условий она сбрасывается и блокируется до 0.5 с непрерывно исправных данных. Модуль поправки ограничен `amax·max_age_s`; поправка не создаёт движение из нуля или смену знака скорости. Обратной связи этой поправки во внутренний фильтр нет.

## 6. Положение и время

Базовый путь интегрируется методом трапеций, а интеграл `δv` добавляется к публикуемому пути:

```text
s ← s + (v_previous + v) · Δt / 2
δs ← δs + (δv_previous + δv) · Δt / 2
s_out = s + δs
```

Без карты публикуется `(s_out,0,0)` от стартовой точки. Начальная скорость получается по пригодной паре колёс. При заданной упорядоченной карте `r(s)` доступна проекция `xyz=r(route_s0+s_out)` с ориентацией по касательной. Направление поворота из разности передней и задней тележек не определяется.

Расчёт выполняется на сетке 20 Гц. Будущие измерения не используются; очереди ограничены. Метки выходов соответствуют времени данных. Ковариации являются оценками неопределённости, их статистическая калибровка требует отдельной проверки.
