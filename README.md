# Резервная одометрия трамвая

ROS 2 Humble-пакет для оценки скорости и пройденного пути по положению контроллера и скоростям двух тележек. Нелинейная модель тяги и торможения дополняется проверками колёсных измерений и адаптацией к сопротивлению движению. При пропусках или недостоверных показаниях используется модельный прогноз.

Текущая версия: **v8**, пакет **0.8.1**, профиль `champion_v8.yaml`. GNSS используется в офлайн-проверке точности. Рабочая нода подписана только на три входных топика трамвая.

## Посмотреть решение

**Tram Odometry Lab** объединяет карту поездки, графики скорости и пути, сравнение моделей и разбор отказов датчиков. Жюри может выбрать запись, сравнить v8 с показаниями тележек, воспроизвести пропуски данных и выгрузить результаты.

## Сборка и запуск

В Ubuntu 22.04 с установленными ROS 2 Humble и colcon:

```bash
bash submission/build.sh
bash submission/run.sh --clock
```

В другом терминале, из корня проекта:

```bash
source /opt/ros/humble/setup.bash
source install_main/setup.bash
ros2 bag play /absolute/path/to/bag --clock 100 --topics   /vehicle/driver_position_cmd   /vehicle/front_bogie_velocity   /vehicle/rear_bogie_velocity
```

Выходы: `/result/velocity` (`tram_vehicle_msgs/msg/VelocitySensor`) и `/result/position` (`nav_msgs/msg/Odometry`). Расчётная частота — 20 Гц. Без карты положение представлено относительной координатой `(s, 0, 0)` вдоль пути.

## Результаты

На сохранённом наборе из 19 проверочных записей:

| Показатель | Значение |
|---|---:|
| RMSE скорости, среднее по группам | 0.114550 м/с |
| RMSE скорости, все сопоставленные точки | 0.216407 м/с |
| RMSE скорости в исходных сценариях отказов | 0.538287 м/с |
| RMSE относительного пути на непрерывных участках GNSS | 4.595481 м |

Набор использовался повторно при сравнении вариантов. Эти показатели не являются результатом независимого финального теста. Ошибка пути рассчитана по интегралу скорости GNSS; точность пространственной XYZ-траектории не измерена. Методика и исходные таблицы приведены в [отчёте](submission/VALIDATION_V8.md).

## Структура

- `src/` — два ROS-пакета, модель, конфигурация и запуск;
- `submission/` — инструкция и материалы для жюри;
- `tests/` — проверки модели и ROS-интерфейсов;
- `tools/` — загрузка данных, анализ и измерения;
- `reports/`, `research/` — результаты и история экспериментов.

Исторические профили сохранены для воспроизводимости. В установку входит один профиль v8. [Описание набора данных](docs/ORGANIZER_README.md), [зафиксированный состав модели](research/adjudication/SELECTED_SOURCE.json).
